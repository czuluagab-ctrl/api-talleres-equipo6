# API de Gestión de Inscripciones a Talleres

Proyecto desarrollado para la asignatura de Programación Avanzada con enfoque en QA.

## Estructura del Proyecto
- `src/controllers/`: Lógica de negocio y controladores de las operaciones.
- `src/models/`: Modelos de datos ficticios (Estudiantes, Talleres, Inscripciones).
- `src/routes/`: Rutas HTTP definidas para la API.
- `src/app.js`: Servidor principal Express.

## Cómo ejecutar localmente
1. Abre esta carpeta en Visual Studio Code.
2. Abre la terminal (`Ctrl + ~`).
3. Ejecuta el comando: `npm start`
4. La API estará corriendo en `http://localhost:3000`.
